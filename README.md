# 除灵实习生 Phase 0 原型

阶段 0 白盒验证 Demo：用 Three.js + Cannon-es 在浏览器里跑通“搜证 → 除灵 → 跑路 → 结算”完整循环，重点验证“暴怒值张力”和“廉价文具物理喜剧”是否成立。

设计档案与每次迭代的方案记录见 [DESIGN.md](./DESIGN.md)。

## 运行

```bash
npm start
```

然后打开 <http://127.0.0.1:4173>。依赖已复制到 `vendor/`，也可以直接运行 `node server.js`。

## 操作

- `WASD` / 方向键：移动
- `Shift`：奔跑（消耗体力）
- 鼠标点击画面：锁定鼠标（`Esc` 释放）
- 鼠标移动：控制镜头方向
- 投掷类道具：右键 / 左键进入瞄准，再按左键或 `F` 射出
- 封印 / 陷阱：左键直接使用
- `F`：使用当前道具
- `E`：互动（捡道具、看线索、躲柜子、推书架、踢垃圾桶、逃出）
- `Space`：跳跃（可跳上讲台高台、柜子台阶）
- `X` / `Ctrl`：下蹲爬行（桌底潜行，鬼较远时看不见）
- `V`：手机闪光（消耗电量，眩晕鬼 2 秒，有冷却）
- `G`：鞭子抽鬼（消耗体力，命中旋转击退并累计连击，抽空会绊倒）
- 绳索：柱顶附近按 `E` 抓住，`W/S` 横向移动，再按 `E` 松手
- 梯子：靠近按 `E` 抓住，`W/S` 上下爬升，再按 `E` 离开
- `Q` / `1-6`：切换道具
- `C`：圆珠笔 + 橡皮筋 = 自制弹弓
- `Tab`：打开实习笔记（消耗手机电量）

## 已验证的核心循环

1. 侦察搜证：教室黑板“别踩脚印” + 讲台纸条“它怕订书机”。
2. 准备与执行：静默潜行，趁鬼处于“冷静 / 不悦”，从背后用订书机封印；也可以直接扔文具把灵体值打空（莽夫流）。
3. 逃跑结算：封印成功后鬼进入“狂乱”追捕，出口开启，限时逃出；工资结算会扣除器材费、交通费、损坏赔偿。
4. 暴怒五态：冷静 / 不悦 / 愤怒 / 暴怒 / 狂乱，影响鬼的视野、速度和行为；砸鬼、跑步、破坏设施会涨怒，躲柜子、安静、看线索会降怒。
5. 物理喜剧：道具可投掷、弹跳、粘住；修正带陷阱会黏住鬼；胶水可能粘到自己；剪刀可能插进天花板；书架的赔偿会出现在工资单上。
6. 手持反馈：角色带有可见手臂和手，当前选中的道具会实时显示在手上，切换道具时同步替换。
7. 状态反馈：鬼的五个暴怒阶段分别有灵体变色、光环、警告图标、屏幕红晕和紫火特效；拾取/互动与使用道具时角色有不同动作姿势。
8. 道具标注：可拾取道具带有发光圆环和悬浮图标；投掷类道具拆分“瞄准”和“射出”两步，屏幕准星和角色动作会同步变化。
9. 轨迹预览：投掷类道具瞄准时显示虚线抛物线轨迹和落点标记，方便判断作用距离。
10. 脚印惩罚：踩到鬼留下的脚印会涨暴怒、掉体力，并让鬼听见动静。
11. 备用方案：订书机用错坏掉后，20 秒会刷新备用订书机；也可以直接靠文具打空灵体值通关。
12. 鬼压迫感：鬼基础速度整体提高，愤怒以上会随机瞬时冲刺。
13. 真实倒地：垃圾桶、书架可被踢倒并产生真实物理倒地效果；书架倒下会成为阻挡，垃圾桶可以被掠过。
14. 容错与溜鬼：玩家有 3 次被抓机会，被抓后会被击退并获得短暂无敌，可以绕着鬼周旋。
15. 弱点与距离：找到线索后鬼后背显示弱点标记；装备订书机时显示封印范围圈和距离提示。
16. 订书机虚弱：失败时鬼先虚弱 1.6 秒再发怒，成功时虚弱 3 秒再狂暴，不会立刻追人。
17. 出口信标：封印成功后出口上方出现绿色信标，目标提示引导玩家逃跑。
18. 空间体感：教室与走廊扩大，新增绕柱区、讲台高台、柜子台阶、桌底通行、下蹲爬行、黑板擦击退、盆栽/杂物/电话场景事件。
19. 重型击退：新增椅子击退道具；柜顶/讲台通过跳跃抵达，不再使用瞬移式攀爬。
20. 路线与跳跃修正：移除传送式攀爬，任何高处都可跳跃；新增可推动木箱作为跳跃平台。
21. 黑暗与立体动线：整体视野变暗，手机照明与电量关联；移除硬性路线带，改用杂物堆、箱子、墙面承重板、滑梯和绳索自然引导；新增托盘堆、沿墙承重板等垂直结构。
22. 跳跃上限与连贯高架：最多双跳；最高承重板通过高架步道连贯通往走廊；安全屋前清空障碍并增加绿色标识和灯光。
23. 空中救回与手机闪光：掉落途中仍可二段跳救回；`V` 键手机闪光耗电并眩晕鬼 2 秒；游戏中隐藏鼠标。
24. 鬼卡住修复与空间扩容：鬼 0.6 秒无位移自动换目标；内部障碍对鬼可穿透；教室/走廊扩容约 1.5 倍；开始即自动锁定鼠标。
25. 体力与推箱优化：跳跃消耗体力并改为落地必重置；互动提示显示在物体上方；箱子支持点按/长按推动；鬼可上低矮平台。
26. 高度与阻挡修正：墙高翻倍到 7 米，高架抬到 4 米；鬼只能上 0.8 米以下低台；中大物体确认阻挡；杂物可被破坏；输入防重复。
27. 占地与交互扩充：占地约 1.56 倍；桌子/垃圾桶阻挡；杂物撕成碎纸；道具精简到 6 格；血图标可视化；新增绳索攀爬；高架末端实心。
28. 绳索/梯子分工：绳索改为柱子间横向高空移动，纵向改走梯子；碎屑改为米黄色并有碎屑/变形/踢飞三种效果。
29. 绳索方向与高架衔接：修复绳索模型方向为横向；高架折角和末端全部实心验证通过。
30. 操作与技能规则：投掷必须右键瞄准再左键发射；普通命中也会涨暴怒并吸引鬼；鬼新增“鬼影突袭”主动技能。
31. 技能与高架修正：鬼技能改为“鬼影突袭”；绳索横移改 `W/S`；高架物理体加厚防踩空。
32. 推箱与朝向修正：推箱提示跟随箱子，玩家与箱子同步前进；绳索 W 始终朝角色面前；高架改为不可穿透厚实体。
33. 推箱规则统一与全屏：箱子只能通过 E 推，身体不能顶动；绳索朝向实时跟随；高架整体不可穿透；新增 Alt 唤出鼠标 + 全屏按钮。
34. 推箱生效与镜头修正：箱子只能 E 推；移除高架空气墙；Alt 按住显示鼠标、松开隐藏。
35. 全向阻挡与镜头静止：箱子改静态世界阻挡；高架/承重板轴对齐实心；镜头改为移动增量，鼠标不动镜头不动。
36. 防穿墙与边缘视角：推箱会检测前方阻挡，不会推入墙体；鼠标到边缘后镜头持续按方向转动，回中停止。
37. 推箱四方向与实时提示：推箱按箱子实时位置判定，四个水平方向均可推，推到墙边提示仍保留。
38. 四幕节拍与反馈：暴怒阶段触发粉笔/桌震/柜门/心跳事件；命中/被抓/封印有 Hitstop 与慢动作；结算新增节目效果评分 S/A/B/C 与称号。
39. 视野与节奏升级：鬼近身 3 米内必定发现玩家，不悦/愤怒视野扩大；首次惊吓后 20 秒无进展会触发主管催促并涨暴怒。
40. 粒子/环境动画/最佳记录：命中生成粒子；愤怒课桌震动、暴怒柜门震动；localStorage 保存最佳评分与最快时间；冷静/不悦视野提升。
41. 特色放大：视野锥形化可背后偷袭；虚弱 5 秒 + 冲刺 6.0；命中环特效；新增玩具弩与尖叫地雷；四幕全屏色闪与夸张文案。
42. 演出与噪音修正：全屏色闪改为边缘渐变闪；加速跑感知范围 14 米但不直接涨怒，只有带怒噪音才涨怒。
43. 鬼技能补齐：鬼伪装成垃圾桶伏击玩家；第二次躲同一柜子会被记住，搜索时间延长到 6 秒。
44. 行为闭合与互动：书架固定倒下方向并砸鬼；箱子目标位打通高台路线；道具精简到 6 格；新增 G 挑衅键与幕卡演出。
45. 强制连锁教学：首次惊吓后自动教学“修正带陷阱 -> 鬼被黏住 -> 书架压扁 -> 订书机封印”，带黄色目标圈、防软锁回退与结算奖金。
46. 交互可读性：木箱目标改为米色方形框，修正带教学圈保持黄色；书架推倒更快、压鬼判定更宽并真正限制鬼行动；G 互动键常驻 HUD 提示。
47. 鞭子互动：G 改为消耗体力抽鬼，命中旋转击退并显示连击；连击结算有奖金，每 5 连击鬼会发怒强化，抽空会绊倒并吸引鬼；木箱改为绳索柱唯一登高道具。

## 架构约定

- 系统之间不直接互相依赖，通过 `EventBus` 发送 `toast`、`noise`、`speech`、`rage.changed` 等事件。
- 所有数值集中在 `src/config/`，调暴怒曲线、道具伤害、薪资扣款不需要改逻辑代码。
- 物理引擎通过 `src/core/Physics.js` 统一封装；角色控制器直接写速度，接触摩擦保持很低，避免 Cannon 的摩擦求解把玩家移动吃掉。
- 占位资产统一从 `PlaceholderAssets.js` 生成，每个对象带 `userData.assetKey`，后续换正式美术时替换工厂函数即可。

## 美术替换入口

正式美术接入时只改两个位置：

1. `src/core/PlaceholderAssets.js`：把 `makePlayerMesh()`、`makeGhostMesh()`、`makeItemMesh()`、`makePropMesh()` 换成 GLTF 加载；先预加载并缓存，再按 `assetKey` 返回。
2. `src/config/palette.js`：替换占位色板，或改为读取资源目录配置。

场景物件、道具、鬼和玩家都不应在系统代码里硬编码颜色和形状。

## Unity 移植映射

| 本原型 | Unity 对应 |
| --- | --- |
| `src/config/*.js` | ScriptableObject / 关卡配置表 |
| `EventBus.js` | C# 事件 / 消息总线 |
| `GameState.js` | 全局 GameManager 状态 |
| `Physics.js` | PhysX + Collider / Rigidbody 封装 |
| `PlayerSystem.js` | 角色控制器 + CharacterController 或 Rigidbody |
| `GhostSystem.js` | 鬼的状态机 + NavMesh / 自写 AI |
| `RageSystem.js` | 暴怒值数值 + 状态阶段 |
| `ItemSystem.js` | 道具 ScriptableObject + 投掷物对象池 |
| `UISystem.js` | UGUI / UI Toolkit |
| `PlaceholderAssets.js` | Addressables / AssetBundle 资源注册表 |

## 调试接口

浏览器控制台里可以访问 `window.__game`：

```js
__game.start()          // 开始实习
__game.give('pen', 3)   // 给道具
__game.readClue('note') // 读取线索
__game.setRage(90)      // 直接调暴怒值
__game.win()            // 跳过逃跑，直接结算
__game.lose()           // 触发失败结算
```
